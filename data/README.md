# Datos y procedencia

`reference/` contiene el snapshot original INEGI mgem/07 descargado el 11-10-2026: 124 municipios, claves textuales únicas de cinco dígitos, entidad07. Manifest con SHA-256 y procedencia; fecha de vigencia de nombres/claves no informada. Las estadísticas del payload corresponden al Censo2020, no a 2026, y no se usan como precios ni inventario ganadero. Fuente: INEGI, Servicio Web del Catálogo Único.

`synthetic/` contendrá DEMO reproducible: no productores ni identificadores oficiales reales. Los hechos confirmados se crearán mediante comandos de negocio. `db/seed/` tendrá maestros/catálogos y proceso por propietario. Los catálogos del producto no se presentan como oficiales.

Ver [términos INEGI](https://www.inegi.org.mx/inegi/terminos.html) y manifest. No se necesita SNIIM/APIAnything para confirmar importes de una compra.
